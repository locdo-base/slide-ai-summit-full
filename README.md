## Hướng dẫn chạy cục bộ

### Cách 1: Chạy bằng file Batch (Windows)
Nhấp đúp chuột vào file `start.bat`. Trình duyệt sẽ tự động mở trang `http://localhost:5500`.

### Cách 2: Chạy bằng Node.js
```bash
node server.js
```

Truy cập: `http://localhost:5500`
